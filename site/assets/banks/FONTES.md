# Logos dos bancos

As marcas pertencem aos respetivos bancos; aqui servem só para identificar o banco de cada cartão.

| Ficheiro | Origem |
|---|---|
| millennium, cgd, novobanco, montepio, bpi, santander, mbway | Wikimedia Commons (ficheiros SVG das logos, versão original a cores) |
| revolut, n26, wise, visa, mastercard | Simple Icons 13.21.0 (CC0) |
| activobank | Texto simples: não há SVG livre da logo |

Os ficheiros ficam a cores; nos cartões passam a branco com `filter: brightness(0) invert(1)` (ver `css/finora.css`).
